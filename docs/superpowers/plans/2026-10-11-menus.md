# Right-Click Menu and Menu Bar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the timer its right-click menu and a standard menu bar (spec §7), with Control commands that run through the event-reporting command sink, Compare Against, Always on Top, Open Log Folder, About and Quit. Add keyboard shortcuts for the Control commands that the user can change (§7.2), and a Settings window for them and for what a reset with new best times does (§7.1, §7.3) (issue #13).

**Architecture:** `Shortcut` and `Shortcuts` (`App/Shortcuts/`) are plain values: a key matched by the character it types, or by name for keys that type nothing visible; and each Control command's list, stored in `app.toml`'s `[shortcuts]` table with only the commands that differ from the defaults. `TimerMenuState` (`App/Menu/`) is a snapshot of the timer read under its read lock. Pure functions on it decide each item's title and whether it is enabled, and which server-protocol command it sends. `CommandRunner` owns the app's one `EventSink` and runs commands on a serial background queue, then calls `TimerContent.markChanged()` on the main actor. `TimerMenus` builds the menu bar and the right-click menu from the same item lists, validates them, fills Compare Against when it opens, and shows each command's first shortcut without ever firing it. `ShortcutKeys` runs shortcuts from a local key-down monitor while the timer window is key. `SettingsWindowController` (`App/SettingsWindow/`) edits the shortcuts and the reset setting, saving each change at once.

**Tech Stack:** Swift 6, AppKit (`NSMenu`, `NSMenuItem`, `NSEvent`, `NSPopUpButton`, `NSStackView`), Carbon's `kVK_` key codes, livesplit-core's server protocol through `EventSink`, swift-toml, Swift Testing, XCUITest, XcodeGen.

## Global Constraints

- Swift never reimplements timer rules (spec §4). The menus only *read* the timer to decide what is enabled; every change goes through `EventSink.handleCommand` as a server-protocol command, so menu, keyboard and server commands behave the same (§5.1).
- `EventSink`'s callback rules (its doc comments, and the comments on #11): `report` and `decideReset` run on the thread that ran the command. They never call into an `EventSink` and never wait on another command, and `report` returns promptly. Commands that can reset never run on the main thread. `CommandRunner` runs **every** command on its own serial queue, and hops to the main actor with `Task { @MainActor in … }`, never synchronously.
- The timer's read lock is held only while reading `TimerMenuState`, through `SharedTimer.readWith`. Nothing in this plan takes the write lock.
- Server-protocol command names, exactly as livesplit-core's `Command` enum serialises them (`#[serde(tag = "command", rename_all = "camelCase")]`): `splitOrStart`, `reset` (with no `saveAttempt`, so the sink asks `decideReset`), `undoSplit`, `skipSplit`, `pause`, `resume`, `undoAllPauses`, `setCurrentComparison` with `"comparison"`, and `setCurrentTimingMethod` with `"timingMethod"` set to `"RealTime"` or `"GameTime"`. Never `togglePauseOrStart`: it starts a stopped timer (spec §7).
- Until #12, a reset with new best times updates them when `reset_saves_best_times` is absent (spec §7.1): `decideReset` answers `.save` for `nil` and `true`, and `.discard` for `false`.
- Default shortcuts (spec §7.2): Start/Split `Space`, Reset `Backspace`, Undo Split `u`, Skip Split `s`, Pause/Resume `p`, Undo All Pauses none.
- Reserved shortcuts, never recorded and dropped from the file (spec §7.3, §11): `Meta+q`, `Meta+h`, `Alt+Meta+h`, `Meta+m`, `Meta+,`, `Meta+w`.
- Shortcuts are written `Control+Alt+Shift+Meta+key`, modifiers in that order (⌃⌥⇧⌘, as macOS menus show them). A character key is matched by `NSEvent.characters(byApplyingModifiers: [])`, lowercased. A named key is matched by its key code. Only ⇧ ⌃ ⌥ ⌘ count as modifiers.
- Menu items show shortcuts but never fire them: `TimerMenus.menuHasKeyEquivalent(_:for:target:action:)` returns `false`. Shortcuts run only from `ShortcutKeys`, only while the timer window is key, and never on a key repeat.
- Item titles, exactly: **Control**, **Start** / **Split**, **Reset**, **Undo Split**, **Skip Split**, **Pause** / **Resume**, **Undo All Pauses**, **Compare Against**, **Real Time**, **Game Time**, **Always on Top**, **Settings…**, **Open Log Folder**, **About LiveSplit One for macOS**, **Quit**. The app menu's items are **Hide LiveSplit One for macOS**, **Hide Others**, **Show All** and **Quit LiveSplit One for macOS**. The menu bar's menus are **Control**, **Compare Against**, **Window** (**Close**, **Minimize**, **Always on Top**) and **Help**.
- Settings keys (spec §11): `reset_saves_best_times` (absent while the app should ask), and the `[shortcuts]` table with `start_split`, `reset`, `undo_split`, `skip_split`, `pause`, `undo_all_pauses`.
- Every timer command is logged in the `TIMER` category with its source (spec §12.1), as `<name> from the menu: <reply>` or `<name> from the keyboard: <reply>`, where `<reply>` is the server protocol's reply, such as `{"success":null}`.
- Accessibility identifiers on the right-click menu's items (`NSMenuItem.identifier`): `timer-control`, `timer-<command>`, `timer-compare-against`, `timer-always-on-top`.
- Accessibility identifiers in the Settings window: `settings-window`, `reset-best-times` (the popup), `add-shortcut-<command>`, `shortcut-<command>-<n>` (the n-th shortcut's remove button), `shortcut-recorder`, `shortcut-message-<command>`, `restore-default-shortcuts`. `<command>` is the `[shortcuts]` key, such as `start_split`.

## Review Focus

1. **Holding a key down** (a runner leaning on Space): one split, not one per key repeat. `ShortcutKeys` runs nothing on `isARepeat`, and the recorder doesn't record a repeat. Tests in Tasks 8 and 6.
2. **Typing while the Settings window is key**, or recording a shortcut there: no Control command runs. Menu key equivalents never fire, and `ShortcutKeys` only acts on events for the timer window. Tests in Tasks 7 and 8, and the E2E flow in Task 9.
3. **A hand-edited `[shortcuts]` table** with a typo (`Ctrl+u`), a shortcut on two commands, a reserved one (`Meta+q`), an unknown command, or Caps Lock-style capitals (`U`): bad entries are dropped and logged, the rest still work, and `U` reads as `u`. A list holding a number makes the file unreadable, like any wrong type (spec §11). Tests in Task 2.
4. **A reset with new best times**, from the menu or the keyboard, for each value of the setting: the attempt's times are kept for *Ask* and *Update them*, and discarded for *Keep the old ones*. The main thread never waits on it. Tests in Task 5.
5. **The timer changing between opening a menu and choosing an item** (a server reset arrives, the run ends): the command is rejected by livesplit-core, the rejection is logged, and nothing crashes. Pause or Resume is picked from the state when the item is chosen, so the worst case is `AlreadyPaused` or `NotPaused`. Test in Task 5.

### Task 1: `Shortcut`: one key and its modifiers, as text

**Files:**
- Create: `App/Shortcuts/Shortcut.swift`
- Test: `Tests/Unit/ShortcutTests.swift`

**Interfaces:**
- Consumes: nothing new.
- Produces:
  - `struct Shortcut: Hashable, Sendable` with `var key: Key`, `var modifiers: Modifiers`, `init(key: Key, modifiers: Modifiers = [])`, `init?(_ text: String)`, `var description: String` (the text form, `CustomStringConvertible`), `var displayName: String` (⌃⌥⇧⌘ symbols then the key, such as `⌃⇧Space` or `U`).
  - `enum Shortcut.Key: Hashable, Sendable { case character(Character), named(NamedKey) }`.
  - `struct Shortcut.Modifiers: OptionSet, Hashable, Sendable` with `.control`, `.alt`, `.shift`, `.meta`.
  - `enum Shortcut.NamedKey: String, CaseIterable, Sendable` (raw value = the name, such as `"Space"`, `"Numpad1"`), with `var keyCode: UInt16`, `var symbol: String` and `static func forKeyCode(_ code: UInt16) -> NamedKey?`.

Key facts:
- `Character.lowercased()` returns a `String`, which in rare cases is more than one character. A key must stay one character after lowercasing.
- AppKit gives arrow and function keys characters in the private use area (`NSUpArrowFunctionKey` is U+F700). Those are never a character key: they are named keys.
- `+` is both the separator and a key. `"+"` alone is the key `+`, and `"Control++"` is ⌃ with `+`.
- The key codes are Carbon's `kVK_` constants (`import Carbon.HIToolbox`). They name positions, but only keys that are in the same place on every Mac keyboard have names, so matching named keys by key code is safe.

```swift
import Carbon.HIToolbox

/// A keyboard shortcut: one key and the modifiers held with it (spec §7.2). Written as
/// `Control+Alt+Shift+Meta+key`, the modifiers in the order macOS menus show them.
struct Shortcut: Hashable, Sendable, CustomStringConvertible {
    var key: Key
    var modifiers: Modifiers

    enum Key: Hashable, Sendable {
        /// A key matched by the character it types with no modifiers on the current keyboard
        /// layout, as most Mac apps match their shortcuts. Always lowercase.
        case character(Character)
        /// A key that types nothing visible, or is on the numeric keypad: matched by its key code.
        case named(NamedKey)
    }

    struct Modifiers: OptionSet, Hashable, Sendable {
        let rawValue: UInt8
        static let control = Modifiers(rawValue: 1 << 0)
        static let alt = Modifiers(rawValue: 1 << 1)
        static let shift = Modifiers(rawValue: 1 << 2)
        static let meta = Modifiers(rawValue: 1 << 3)

        /// Each modifier with its name in the text form and its symbol, in the order macOS menus
        /// show them: ⌃⌥⇧⌘. The names are livesplit-core's hotkey modifiers' names.
        static let ordered: [(modifier: Modifiers, name: String, symbol: String)] = [
            (.control, "Control", "⌃"), (.alt, "Alt", "⌥"), (.shift, "Shift", "⇧"),
            (.meta, "Meta", "⌘"),
        ]
    }

    init(key: Key, modifiers: Modifiers = []) {
        self.key = key
        self.modifiers = modifiers
    }

    /// Reads the text form, such as `"u"`, `"Numpad1"` or `"Control+Shift+Space"`. `nil` if it
    /// isn't one: an unknown modifier, a modifier twice, or a key that isn't a name or a single
    /// visible character.
    init?(_ text: String) {
        let keyText: Substring
        let modifierText: Substring
        // "+" is the separator and also a key: "+" alone, or "…++" at the end, is the key "+".
        if text == "+" {
            (modifierText, keyText) = ("", "+")
        } else if text.hasSuffix("++") {
            (modifierText, keyText) = (text.dropLast(2), "+")
        } else if let plus = text.lastIndex(of: "+") {
            (modifierText, keyText) = (text[..<plus], text[text.index(after: plus)...])
        } else {
            (modifierText, keyText) = ("", Substring(text))
        }

        var modifiers: Modifiers = []
        if !modifierText.isEmpty {
            for name in modifierText.split(separator: "+", omittingEmptySubsequences: false) {
                guard let entry = Modifiers.ordered.first(where: { $0.name == name }),
                    !modifiers.contains(entry.modifier)
                else { return nil }
                modifiers.insert(entry.modifier)
            }
        }

        if let named = NamedKey(rawValue: String(keyText)) {
            self.init(key: .named(named), modifiers: modifiers)
        } else if let character = Self.keyCharacter(keyText) {
            self.init(key: .character(character), modifiers: modifiers)
        } else {
            return nil
        }
    }

    /// The single visible character a key types, lowercased, or `nil` if `text` isn't one.
    static func keyCharacter(_ text: some StringProtocol) -> Character? {
        guard text.count == 1, let character = text.first,
            !character.isWhitespace, !character.unicodeScalars.contains(where: {
                $0.properties.generalCategory == .control
                    || $0.properties.generalCategory == .privateUse
            })
        else { return nil }
        let lower = character.lowercased()
        guard lower.count == 1 else { return nil }
        return lower.first
    }

    var description: String {
        let names = Modifiers.ordered.filter { modifiers.contains($0.modifier) }.map(\.name)
        let keyText =
            switch key {
            case .character(let character): String(character)
            case .named(let named): named.rawValue
            }
        return (names + [keyText]).joined(separator: "+")
    }

    /// How the Settings window shows it: the modifiers' symbols, then the key, such as `⌃⇧Space`.
    var displayName: String {
        let symbols = Modifiers.ordered.filter { modifiers.contains($0.modifier) }.map(\.symbol)
        let keyText =
            switch key {
            case .character(let character): String(character).uppercased()
            case .named(let named): named.symbol
            }
        return symbols.joined() + keyText
    }
}

        var symbol: String {

            case .numpadDivide: "Keypad ÷"
            case .numpadEnter: "Keypad Enter"
            case .numpadEqual: "Keypad ="
            case .numpadClear: "Keypad Clear"
            default:
                // F1–F20 as they are; Numpad0–Numpad9 as "Keypad 0"–"Keypad 9".
                rawValue.hasPrefix("Numpad")
                    ? "Keypad " + rawValue.dropFirst("Numpad".count) : rawValue
            }
```

```swift
/// Each Control command's shortcuts (spec §7.2), stored in `app.toml`'s `[shortcuts]` table
/// (§11), which holds only the commands that differ from the defaults.
struct Shortcuts: Codable, Equatable, Sendable {
    static let defaults: [ControlCommand: [Shortcut]] = [
        .startSplit: [Shortcut(key: .named(.space))],
        .reset: [Shortcut(key: .named(.backspace))],
        .undoSplit: [Shortcut(key: .character("u"))],
        .skipSplit: [Shortcut(key: .character("s"))],
        .pause: [Shortcut(key: .character("p"))],
        .undoAllPauses: [],
    ]

    /// The app's own menu shortcuts: Quit, Hide, Hide Others, Minimize, Settings and Close
    /// (spec §7.3). They can't be recorded, and are dropped from the file.
    static let reserved: Set<Shortcut> = [
        Shortcut(key: .character("q"), modifiers: .meta),
        Shortcut(key: .character("h"), modifiers: .meta),
        Shortcut(key: .character("h"), modifiers: [.alt, .meta]),
        Shortcut(key: .character("m"), modifiers: .meta),
        Shortcut(key: .character(","), modifiers: .meta),
        Shortcut(key: .character("w"), modifiers: .meta),
    ]

    /// Why adding a shortcut was refused.
    enum Refusal: Equatable, Sendable {
        case reserved
        case usedBy(ControlCommand)
    }

    /// The commands whose shortcuts differ from the defaults.
    private var changed: [ControlCommand: [Shortcut]] = [:]
    /// A line for each entry reading the file dropped, for the log. Not a setting: not
    /// compared, not saved.
    private(set) var dropped: [String] = []

    init() {}

    var isDefault: Bool { changed.isEmpty }

    func shortcuts(for command: ControlCommand) -> [Shortcut] {
        changed[command] ?? Self.defaults[command] ?? []
    }

    /// The command a shortcut runs, if any.
    func command(for shortcut: Shortcut) -> ControlCommand? {
        ControlCommand.allCases.first { shortcuts(for: $0).contains(shortcut) }
    }

    /// Adds `shortcut` to `command`'s list, unless the app keeps it for its menus or another
    /// command has it. Adding one the command already has changes nothing.
    mutating func add(_ shortcut: Shortcut, to command: ControlCommand) -> Refusal? {
        if Self.reserved.contains(shortcut) { return .reserved }
        if let other = self.command(for: shortcut) {
            return other == command ? nil : .usedBy(other)
        }
        set(shortcuts(for: command) + [shortcut], for: command)
        return nil
    }

    mutating func remove(_ shortcut: Shortcut, from command: ControlCommand) {
        set(shortcuts(for: command).filter { $0 != shortcut }, for: command)
    }

    mutating func restoreDefaults() {
        changed = [:]
    }

    private mutating func set(_ shortcuts: [Shortcut], for command: ControlCommand) {
        changed[command] = shortcuts == Self.defaults[command] ? nil : shortcuts
    }

    static func == (lhs: Shortcuts, rhs: Shortcuts) -> Bool { lhs.changed == rhs.changed }

    /// Reads the table, resolving every command in order (spec §11): an entry that isn't a
    /// shortcut, is reserved, or that an earlier command already has, is dropped into `dropped`.
    /// A list of the wrong type throws, which makes the file unreadable.
    init(from decoder: any Decoder) throws {
        let table = try decoder.singleValueContainer().decode([String: [String]].self)
        var seen: [Shortcut: ControlCommand] = [:]
        for command in ControlCommand.allCases {
            let listed =
                table[command.rawValue]
                ?? (Self.defaults[command] ?? []).map(\.description)
            var kept: [Shortcut] = []
            for text in listed {
                let problem: String?
                if let shortcut = Shortcut(text) {
                    if Self.reserved.contains(shortcut) {
                        problem = "the app keeps it for its menus"
                    } else if let other = seen[shortcut] {
                        problem = "\(other.rawValue) already has it"
                    } else {
                        problem = nil
                        seen[shortcut] = command
                        kept.append(shortcut)
                    }
                } else {
                    problem = "it isn't a shortcut"
                }
                if let problem {
                    dropped.append("\"\(text)\" for \(command.rawValue): \(problem)")
                }
            }
            set(kept, for: command)
        }
    }

    /// Writes only the commands that differ from the defaults, so a later version's new
    /// defaults reach anyone who never changed them.
    func encode(to encoder: any Encoder) throws {
        var container = encoder.singleValueContainer()
        try container.encode(
            Dictionary(
                uniqueKeysWithValues: changed.map { ($0.key.rawValue, $0.value.map(\.description)) }
            ))
    }
}
```

Note: a shortcut listed twice for the same command is dropped the second time with "start_split already has it", which names the same command. That's accurate enough for a hand-edited file.

```swift
    /// The shortcut a key press is, or `nil` for one that is neither a named key nor a key that
    /// types one visible character (a dead key alone, say). Only ⇧ ⌃ ⌥ ⌘ count: Caps Lock and the
    /// function and numeric-pad flags AppKit adds by itself don't (spec §7.2).

        guard event.type == .keyDown else { return nil }
        let flags = event.modifierFlags
        var modifiers: Modifiers = []
        if flags.contains(.control) { modifiers.insert(.control) }
        if flags.contains(.option) { modifiers.insert(.alt) }
        if flags.contains(.shift) { modifiers.insert(.shift) }
        if flags.contains(.command) { modifiers.insert(.meta) }

            self.init(key: .named(named), modifiers: modifiers)
        } else if let typed = event.characters(byApplyingModifiers: []),
            let character = Self.keyCharacter(typed)
```

```swift
import LiveSplitCore

/// What the menus need to know about the timer, read under its read lock: which items are
/// enabled, their titles, and Compare Against's ticks (spec §7). Reading never changes the timer.
struct TimerMenuState: Equatable, Sendable {
    var phase: TimerPhase
    /// The current segment's index, or -1 before a run starts and after it ends, as
    /// livesplit-core's `currentSplitIndex()` gives it.
    var splitIndex: Int
    var segmentCount: Int
    /// The run's comparisons, custom ones first, as livesplit-core lists them.
    var comparisons: [String]
    var currentComparison: String
    var timingMethod: TimingMethod

    /// Reads the state, holding the timer's read lock only while reading (spec §5.1).
    static func read(from timer: SharedTimerRef) -> TimerMenuState {
        var state: TimerMenuState!
        timer.readWith { timer in
            let run = timer.getRun()
            state = TimerMenuState(
                phase: TimerPhase(rawValue: timer.currentPhase()) ?? .notRunning,
                splitIndex: Int(timer.currentSplitIndex()),
                segmentCount: Int(run.len()),
                comparisons: (0..<run.comparisonsLen()).map { run.comparison($0) },
                currentComparison: timer.currentComparison(),
                timingMethod: TimingMethod(rawValue: timer.currentTimingMethod()) ?? .realTime)
        }
        return state
    }

    private var attemptInProgress: Bool { phase == .running || phase == .paused }

    /// Whether the command's menu item is enabled: items that can't be used are disabled, not
    /// hidden (spec §7). These follow livesplit-core's own checks, so an enabled item isn't
    /// rejected unless the timer changes first.
    func isEnabled(_ command: ControlCommand) -> Bool {
        switch command {
        case .startSplit: phase == .notRunning || phase == .running
        case .reset: phase != .notRunning
        case .undoSplit: phase == .ended || (attemptInProgress && splitIndex > 0)
        case .skipSplit: attemptInProgress && splitIndex + 1 < segmentCount
        case .pause: attemptInProgress
        case .undoAllPauses: phase != .notRunning
        }
    }

    /// The menu item's title: Start/Split and Pause/Resume follow the timer (spec §7).
    func title(for command: ControlCommand) -> String {
        switch command {
        case .startSplit: phase == .notRunning ? "Start" : "Split"
        case .reset: "Reset"
        case .undoSplit: "Undo Split"
        case .skipSplit: "Skip Split"
        case .pause: phase == .paused ? "Resume" : "Pause"
        case .undoAllPauses: "Undo All Pauses"
        }
    }

    /// The command to send now, or `nil` if the item is disabled. Pause sends `pause` or
    /// `resume`, never `togglePauseOrStart`, which would start a stopped timer (spec §7).
    func command(for command: ControlCommand) -> TimerCommand? {
        guard isEnabled(command) else { return nil }
        return switch command {
        case .startSplit: .splitOrStart
        case .reset: .reset
        case .undoSplit: .undoSplit
        case .skipSplit: .skipSplit
        case .pause: phase == .paused ? .resume : .pause
        case .undoAllPauses: .undoAllPauses
        }
    }
}
```

```swift
/// sink (spec §5.1, §7), on a serial background queue: a reset with new best times waits for
/// `decideReset` on the command's thread, which must never be the main thread (§5.3).
final class CommandRunner: Sendable {
    private let sink: EventSink
    private let queue = DispatchQueue(label: "dev.alexcosta.livesplit-one-macos.commands")
    private let preference: ResetPreference
    private let changed: @MainActor @Sendable () -> Void
    private let log: Log

    /// the change at once (`TimerContent.markChanged()`).

        self.preference = preference
        self.changed = changed
        self.log = log
        sink = EventSink(
            timer: timer,
            // Runs on the command's thread: hand over to the main actor and return at once.
            report: { _ in Task { @MainActor in changed() } },
            // Until #12 asks, *Ask* (nil) updates the best times, livesplit-core's default
            // (spec §7.1).
            decideReset: { (preference.value ?? true) ? .save : .discard })
    }

    /// Runs `command` on the queue, logs it with its source and reply, tells the window, then
    /// calls `completion` with the reply, on the queue.
    func run(
        _ command: TimerCommand, from source: CommandSource,
        completion: (@Sendable (String) -> Void)? = nil
    ) {
        let json = command.json
        let name = command.logName
        queue.async { [sink, log, changed] in
            let reply = sink.handleCommand(json)
            log.record(.timer, "\(name) from \(source.rawValue): \(reply)")
            Task { @MainActor in changed() }
            completion?(reply)
        }
    }

    /// What a reset with new best times does from now on (spec §7.1).
    func setResetSavesBestTimes(_ value: Bool?) {
        preference.value = value
    }
}

/// `reset_saves_best_times`, shared between the main actor, which changes it, and the command
/// queue, which reads it in `decideReset`.
private final class ResetPreference: Sendable {
    private let stored: Mutex<Bool?>

    init(_ value: Bool?) { stored = Mutex(value) }

    var value: Bool? {
        get { stored.withLock { $0 } }
        set { stored.withLock { $0 = newValue } }
    }
}
```

Note: `ResetPreference.value` has a setter on a `let` property of a class, which Swift allows (`preference.value = value` mutates the object, not the reference).

```swift
import AppKit

/// Records the next key press as a shortcut (spec §7.3). Esc cancels. It takes key equivalents
/// too, so ⌘-combinations reach it before the menus, and the window can refuse ⌘Q rather than
/// quit.
@MainActor
final class KeyRecorderView: NSView {
    private let onRecord: (Shortcut) -> Void
    private let onCancel: () -> Void

    init(onRecord: @escaping (Shortcut) -> Void, onCancel: @escaping () -> Void) {
        self.onRecord = onRecord
        self.onCancel = onCancel
        super.init(frame: .zero)
        let label = NSTextField(labelWithString: "Press a key…")
        label.translatesAutoresizingMaskIntoConstraints = false
        addSubview(label)
        NSLayoutConstraint.activate([
            label.leadingAnchor.constraint(equalTo: leadingAnchor, constant: 8),
            label.trailingAnchor.constraint(equalTo: trailingAnchor, constant: -8),
            label.topAnchor.constraint(equalTo: topAnchor, constant: 3),
            label.bottomAnchor.constraint(equalTo: bottomAnchor, constant: -3),
        ])
        wantsLayer = true
        layer?.cornerRadius = 4
        layer?.borderWidth = 1
        layer?.borderColor = NSColor.keyboardFocusIndicatorColor.cgColor
        setAccessibilityElement(true)
        setAccessibilityRole(.textField)
        setAccessibilityLabel("Press a key for the shortcut")
        setAccessibilityIdentifier("shortcut-recorder")
    }

    @available(*, unavailable)
    required init?(coder: NSCoder) {
        fatalError("KeyRecorderView is built in code")
    }

    override var acceptsFirstResponder: Bool { true }

    override func keyDown(with event: NSEvent) {
        record(event)
    }

    override func performKeyEquivalent(with event: NSEvent) -> Bool {
        guard window?.firstResponder === self, event.type == .keyDown else {
            return super.performKeyEquivalent(with: event)
        }
        record(event)
        return true
    }

    private func record(_ event: NSEvent) {
        guard !event.isARepeat else { return }
        guard let shortcut = Shortcut(event: event) else {
            NSSound.beep()
            return
        }
        // The handlers rebuild the row, which removes this view: keep it alive until they return.
        withExtendedLifetime(self) {
            if shortcut == Shortcut(key: .named(.escape)) {
                onCancel()
            } else {
                onRecord(shortcut)
            }
        }
    }
}
```

```swift
import AppKit

/// The Settings window's contents (spec §7.3): what a reset with new best times does, and each
/// Control command's shortcuts. Every change is saved at once, then `onChange` runs, so the
/// menus and the command queue follow it.
@MainActor
final class SettingsViewController: NSViewController {
    /// The reset choices, in the order the popup shows them, with the value each saves (§7.1).
    static let resetChoices: [(title: String, value: Bool?)] = [
        ("Ask", nil), ("Update them", true), ("Keep the old ones", false),
    ]

    private let store: SettingsStore
    private let onChange: () -> Void
    private let resetPopUp = NSPopUpButton()
    private let shortcutRows = NSStackView()
    /// The command whose next shortcut is being recorded, if any.
    private(set) var recording: ControlCommand?
    /// Why a shortcut wasn't added, shown under its command's row until the next change.
    private(set) var messages: [ControlCommand: String] = [:]

    init(store: SettingsStore, onChange: @escaping () -> Void) {
        self.store = store
        self.onChange = onChange
        super.init(nibName: nil, bundle: nil)
        title = "Settings"
    }

    @available(*, unavailable)
    required init?(coder: NSCoder) {
        fatalError("SettingsViewController is built in code")
    }

    override func loadView() {
        resetPopUp.addItems(withTitles: Self.resetChoices.map(\.title))
        resetPopUp.target = self
        resetPopUp.action = #selector(resetChoiceChanged(_:))
        resetPopUp.setAccessibilityIdentifier("reset-best-times")
        resetPopUp.setAccessibilityLabel("When a reset has new best times")
        let resetRow = NSStackView(views: [
            NSTextField(labelWithString: "When a reset has new best times:"), resetPopUp,
        ])

        shortcutRows.orientation = .vertical
        shortcutRows.alignment = .leading
        shortcutRows.spacing = 8

        let restore = NSButton(
            title: "Restore Defaults", target: self, action: #selector(restoreDefaults(_:)))
        restore.setAccessibilityIdentifier("restore-default-shortcuts")

        let stack = NSStackView(views: [
            heading("General"), resetRow, heading("Shortcuts"), shortcutRows, restore,
        ])
        stack.orientation = .vertical
        stack.alignment = .leading
        stack.spacing = 12
        stack.edgeInsets = NSEdgeInsets(top: 20, left: 20, bottom: 20, right: 20)
        view = stack
        reload()
    }

    /// Shows the settings as they are saved now.
    func reload() {
        let settings = store.settings
        resetPopUp.selectItem(
            at: Self.resetChoices.firstIndex { $0.value == settings.resetSavesBestTimes } ?? 0)
        for row in shortcutRows.arrangedSubviews { row.removeFromSuperview() }
        var recorder: KeyRecorderView?
        for command in ControlCommand.allCases {
            let (row, rowRecorder) = makeRow(for: command, shortcuts: settings.shortcuts)
            shortcutRows.addArrangedSubview(row)
            recorder = recorder ?? rowRecorder
        }
        if let recorder { view.window?.makeFirstResponder(recorder) }
    }

    private func heading(_ text: String) -> NSTextField {
        let label = NSTextField(labelWithString: text)
        label.font = .boldSystemFont(ofSize: NSFont.systemFontSize)
        return label
    }

    /// One command's row: its name, a button per shortcut that removes it, and **+** (or the
    /// recorder while recording), with any refusal under it.
    private func makeRow(for command: ControlCommand, shortcuts: Shortcuts) -> (
        NSView, KeyRecorderView?
    ) {
        let index = ControlCommand.allCases.firstIndex(of: command)!
        let name = NSTextField(labelWithString: command.name)
        name.widthAnchor.constraint(equalToConstant: 130).isActive = true

        let keys = NSStackView()
        keys.orientation = .horizontal
        keys.spacing = 6
        for (position, shortcut) in shortcuts.shortcuts(for: command).enumerated() {
            let token = NSButton(
                title: "\(shortcut.displayName)  ✕", target: self,
                action: #selector(removeShortcut(_:)))
            token.controlSize = .small
            // A command has far fewer than 100 shortcuts.
            token.tag = index * 100 + position
            token.setAccessibilityIdentifier("shortcut-\(command.rawValue)-\(position)")
            token.setAccessibilityLabel("Remove \(shortcut.displayName) from \(command.name)")
            keys.addArrangedSubview(token)
        }

        var recorder: KeyRecorderView?
        if recording == command {
            let view = KeyRecorderView(
                onRecord: { [weak self] in self?.record($0) },
                onCancel: { [weak self] in self?.cancelRecording() })
            keys.addArrangedSubview(view)
            recorder = view
        } else {
            let add = NSButton(title: "+", target: self, action: #selector(addShortcut(_:)))
            add.controlSize = .small
            add.tag = index
            add.setAccessibilityIdentifier("add-shortcut-\(command.rawValue)")
            add.setAccessibilityLabel("Add a shortcut to \(command.name)")
            keys.addArrangedSubview(add)
        }

        let line = NSStackView(views: [name, keys])
        line.orientation = .horizontal
        guard let message = messages[command] else { return (line, recorder) }
        let note = NSTextField(labelWithString: message)
        note.textColor = .secondaryLabelColor
        note.setAccessibilityIdentifier("shortcut-message-\(command.rawValue)")
        let column = NSStackView(views: [line, note])
        column.orientation = .vertical
        column.alignment = .leading
        column.spacing = 2
        return (column, recorder)
    }

    @objc private func resetChoiceChanged(_ sender: NSPopUpButton) {
        let value = Self.resetChoices[sender.indexOfSelectedItem].value
        store.update { $0.resetSavesBestTimes = value }
        onChange()
    }

    @objc private func addShortcut(_ sender: NSButton) {
        recording = ControlCommand.allCases[sender.tag]
        messages = [:]
        reload()
    }

    @objc private func removeShortcut(_ sender: NSButton) {
        let command = ControlCommand.allCases[sender.tag / 100]
        let shortcut = store.settings.shortcuts.shortcuts(for: command)[sender.tag % 100]
        store.update { $0.shortcuts.remove(shortcut, from: command) }
        messages = [:]
        onChange()
        reload()
    }

    @objc private func restoreDefaults(_ sender: NSButton) {
        store.update { $0.shortcuts.restoreDefaults() }
        recording = nil
        messages = [:]
        onChange()
        reload()
    }

    private func record(_ shortcut: Shortcut) {
        guard let command = recording else { return }
        recording = nil
        var shortcuts = store.settings.shortcuts
        switch shortcuts.add(shortcut, to: command) {
        case nil:
            store.update { $0.shortcuts = shortcuts }
            onChange()
        case .reserved:
            messages[command] = "\(shortcut.displayName) is kept for the app's menus."
        case .usedBy(let other):
            messages[command] = "\(shortcut.displayName) is already used by \(other.name)."
        }
        reload()
    }

    private func cancelRecording() {
        recording = nil
        reload()
    }
}
```

Note: `record(_:)` calls `onChange()` even when `add` returned `nil` because the command already had the shortcut, in which case `store.update` saved nothing. That's harmless: `onChange` only refreshes the menus.

**Interfaces:**
- Consumes: `Shortcut(event:)` (Task 3), `Shortcuts.command(for:)` (Task 2), `TimerMenus.perform(_:from:)` (Task 7).
- Produces: `final class ShortcutKeys` with `init(window: NSWindow, shortcuts: @escaping @MainActor () -> Shortcuts, perform: @escaping @MainActor (ControlCommand) -> Void)`, `func install()`, and `func consumes(_ event: NSEvent) -> Bool`.

Key facts:
- A local monitor (`NSEvent.addLocalMonitorForEvents`) sees every key-down in the app before key equivalents and the responder chain. Returning `nil` stops the event; returning it lets AppKit carry on.
- The monitor's handler runs on the main thread. `MainActor.assumeIsolated` returns a `Bool` from it, since `NSEvent` isn't `Sendable` and can't be returned from that call.
- A key that is a shortcut is consumed even when its command is disabled, so pressing Space after the run ended doesn't beep. A key repeat of a shortcut is consumed and runs nothing (Review Focus 1). A key that isn't a shortcut goes on, so ⌘Q and the rest still reach the menu bar.
- Only events for the timer window count, compared by window number, so the Settings window's keys never run a command (Review Focus 2).
- A borderless window can be minimized only if its style mask has `.miniaturizable`. That adds no title bar.

```swift
import AppKit

/// Runs the Control commands' shortcuts while the timer window is key (spec §7.2), from a local
/// monitor, before the menus see the key. The menus only show the shortcuts.
@MainActor
final class ShortcutKeys {
    private let window: NSWindow
    private let shortcuts: @MainActor () -> Shortcuts
    private let perform: @MainActor (ControlCommand) -> Void
    private var monitor: Any?

    init(
        window: NSWindow, shortcuts: @escaping @MainActor () -> Shortcuts,
        perform: @escaping @MainActor (ControlCommand) -> Void
    ) {
        self.window = window
        self.shortcuts = shortcuts
        self.perform = perform
    }

    /// Starts watching key presses, for the rest of the app's life.
    func install() {
        guard monitor == nil else { return }
        monitor = NSEvent.addLocalMonitorForEvents(matching: .keyDown) { [weak self] event in
            // AppKit calls this on the main thread.
            let consumed = MainActor.assumeIsolated { self?.consumes(event) ?? false }
            return consumed ? nil : event
        }
    }

    /// Runs the shortcut's command, if `event` is one for the timer window. Returns whether the
    /// event was a shortcut, in which case nothing else should see it. A key repeat runs nothing,
    /// so holding a key down runs its command once.
    func consumes(_ event: NSEvent) -> Bool {
        guard event.windowNumber == window.windowNumber,
            let shortcut = Shortcut(event: event),
            let command = shortcuts().command(for: shortcut)
        else { return false }
        if !event.isARepeat { perform(command) }
        return true
    }
}
```

```swift
import XCTest

/// The right-click menu, the menu bar and the keyboard shortcuts as a user uses them (spec §7,
/// §14.3).
final class MenuTests: XCTestCase {
    @MainActor
    private func launched() -> E2EApp {
        let e2e = E2EApp()
        e2e.launch()
        XCTAssertTrue(e2e.timerWindow.waitForExistence(timeout: 10))
        return e2e
    }

    /// Right-clicks the timer and opens Control. Returns the right-click menu's item for
    /// `command`, such as `start_split`.
    @MainActor
    private func controlItem(_ command: String, _ e2e: E2EApp) -> XCUIElement {
        e2e.timerWindow.rightClick()
        let control = e2e.app.menuItems["timer-control"]
        XCTAssertTrue(control.waitForExistence(timeout: 5))
        control.hover()
        let item = control.menuItems["timer-\(command)"]
        XCTAssertTrue(item.waitForExistence(timeout: 5))
        return item
    }

    @MainActor
    private func closeMenus(_ e2e: E2EApp) {
        e2e.app.typeKey(.escape, modifierFlags: [])
        e2e.app.typeKey(.escape, modifierFlags: [])
    }

    /// Waits until the log holds `text` `count` times.
    @MainActor
    private func waitForLog(_ text: String, count: Int = 1, _ e2e: E2EApp) {
        let deadline = Date().addingTimeInterval(10)
        while Date() < deadline {
            let log = e2e.logText(containing: text, timeout: 1) ?? ""
            if log.components(separatedBy: text).count - 1 >= count { return }
        }
        XCTFail("the log doesn't hold \"\(text)\" \(count) times")
    }

    @MainActor
    func testControlItemsFollowTheTimer() {
        let e2e = launched()

        let start = controlItem("start_split", e2e)
        XCTAssertEqual(start.title, "Start")
        XCTAssertFalse(e2e.app.menuItems["timer-reset"].isEnabled)
        XCTAssertFalse(e2e.app.menuItems["timer-undo_split"].isEnabled)
        start.click()
        waitForLog("Start/Split from the menu", e2e)

        let split = controlItem("start_split", e2e)
        XCTAssertEqual(split.title, "Split")
        XCTAssertTrue(e2e.app.menuItems["timer-pause"].isEnabled)
        split.click()  // One segment: the run ends.
        waitForLog("Start/Split from the menu", count: 2, e2e)

        let undo = controlItem("undo_split", e2e)
        XCTAssertTrue(undo.isEnabled)
        XCTAssertFalse(e2e.app.menuItems["timer-start_split"].isEnabled)
        undo.click()
        waitForLog("Undo Split from the menu", e2e)

        let reset = controlItem("reset", e2e)
        XCTAssertTrue(reset.isEnabled)
        XCTAssertEqual(e2e.app.menuItems["timer-start_split"].title, "Split")
        reset.click()
        waitForLog("Reset from the menu", e2e)

        XCTAssertEqual(controlItem("start_split", e2e).title, "Start")
        XCTAssertFalse(e2e.app.menuItems["timer-reset"].isEnabled)
        closeMenus(e2e)
    }

    @MainActor
    func testSpaceStartsTheTimer() {
        let e2e = launched()
        e2e.app.typeKey(" ", modifierFlags: [])
        waitForLog("Start/Split from the keyboard", e2e)
        XCTAssertEqual(controlItem("start_split", e2e).title, "Split")
        closeMenus(e2e)
    }

    @MainActor
    func testAShortcutAddedInSettingsRunsItsCommand() {
        let e2e = launched()
        e2e.app.typeKey(",", modifierFlags: .command)
        let settings = e2e.app.windows["settings-window"]
        XCTAssertTrue(settings.waitForExistence(timeout: 5))

        settings.buttons["add-shortcut-start_split"].click()
        e2e.app.typeKey("k", modifierFlags: [])
        XCTAssertTrue(settings.buttons["shortcut-start_split-1"].waitForExistence(timeout: 5))
        let saved = e2e.settingsText(containing: "\"k\"")
        XCTAssertNotNil(saved, "app.toml doesn't hold the new shortcut")
        XCTAssertTrue(saved?.contains("start_split") == true)

        // Close (⌘W) from the Window menu, then the timer window is key again.
        e2e.app.typeKey("w", modifierFlags: .command)
        XCTAssertTrue(settings.waitForNonExistence(timeout: 5))
        e2e.app.typeKey("k", modifierFlags: [])
        waitForLog("Start/Split from the keyboard", e2e)
    }

    @MainActor
    func testCompareAgainstAndTheTimingMethod() {
        let e2e = launched()
        for choice in ["Best Segments", "Game Time"] {
            e2e.timerWindow.rightClick()
            let compare = e2e.app.menuItems["timer-compare-against"]
            XCTAssertTrue(compare.waitForExistence(timeout: 5))
            compare.hover()
            let item = compare.menuItems[choice]
            XCTAssertTrue(item.waitForExistence(timeout: 5))
            item.click()
        }
        waitForLog(#"Compare Against Best Segments from the menu: {"success":null}"#, e2e)
        waitForLog(#"Game Time from the menu: {"success":null}"#, e2e)
    }

    @MainActor
    func testAlwaysOnTopFromTheMenuIsSaved() {
        let e2e = launched()
        e2e.timerWindow.rightClick()
        let item = e2e.app.menuItems["timer-always-on-top"]
        XCTAssertTrue(item.waitForExistence(timeout: 5))
        item.click()
        XCTAssertNotNil(e2e.settingsText(containing: "always_on_top = true"))
    }

    @MainActor
    func testCommandQQuits() {
        let e2e = launched()
        e2e.app.typeKey("q", modifierFlags: .command)
        XCTAssertTrue(e2e.app.wait(for: .notRunning, timeout: 10))
    }
}
```
