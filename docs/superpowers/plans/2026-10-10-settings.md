# Settings Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Keep the app's settings in `~/Library/Application Support/livesplit-one-macos/app.toml`, read at launch and written when one changes, and recover from a broken file by keeping it as `app.toml.bad` and using the defaults (issue #16).

**Architecture:** `Settings` is a plain value with every setting from spec §11, encoded to TOML through `Codable` with explicit snake_case keys, using [swift-toml](https://github.com/mattt/swift-toml). `SettingsStore`, on the main actor, loads it once at launch and saves it atomically after each `update` that changes something. A file that can't be read or parsed is moved aside to `app.toml.bad`; if even that fails, the store stops saving for the session so it never overwrites a file it couldn't read. Failures go to `Log` (#17). Later issues read and change settings through `SettingsStore.update`; this issue adds no UI.

**Tech Stack:** Swift 6, Foundation, swift-toml 2.0.0 (toml++ underneath), Swift Testing, XCUITest, XcodeGen.

**Spec:** `docs/superpowers/specs/2026-10-09-livesplit-one-macos-design.md`, sections 10 (the `app.toml` row), 11, 14.1 and 14.2. Issue: #16.

**Branch and worktree:** `feat/settings`, at `../livesplit-one-macos-wt/settings`. **PR title:** `feat: store settings in app.toml`. **PR body:** `Closes #16`, using the pull request template. One pull request for the whole plan; each task is one commit.

## Global Constraints

- Settings folder: `~/Library/Application Support/livesplit-one-macos/`, file `app.toml` (spec §11). Broken files are kept as `app.toml.bad` in the same folder; an older `app.toml.bad` is replaced.
- The file holds exactly what spec §11 lists: the last splits and layout paths, the recent splits and layouts (10 each, most recent first), the window frame per layout path, Always on Top, and the last Connect to Server URL. Nothing else.
- TOML keys, fixed here and in spec §11: `last_splits`, `last_layout`, `recent_splits`, `recent_layouts`, `always_on_top`, `last_server_url`, and an array of tables `windows`, each with `layout`, `x`, `y`, `width`, `height`. Keys come from explicit `CodingKeys`, never a key strategy, so a path is never rewritten as a key.
- Every key is optional when reading: a missing key takes its default, an unknown key is ignored. A key with the wrong type makes the file broken.
- Read at launch, written only when a setting changes (spec §11). Launching never creates the file.
- Writes are atomic (`Data.WritingOptions.atomic`): a crash or full disk mid-write leaves the old file whole.
- swift-toml is pinned with `exactVersion: 2.0.0` in `project.yml`. The generated project and its `Package.resolved` aren't committed, so the pin is the only thing fixing the version. Renovate updates it (`fix(deps)`, since it ships).
- `SettingsStore` is `@MainActor`. Every setting is changed from the main thread (menu items, windows, sheets).
- Launch arguments for tests are compiled only into Debug builds (`#if DEBUG`).
- Swift is formatted with `swift format` using `.swift-format` and must pass `swift format lint --strict`.
- Commits: Conventional Commits, signed, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **A file the app can't read and can't move aside** (the folder is read-only, or `app.toml` belongs to another user): the app runs on defaults, logs why, and never overwrites `app.toml` that session, so a user's hand-edited file isn't lost to a failed read. Test in Task 2.
2. **Paths that aren't plain words** (spaces, quotes, backslashes, dots, `#`, accents, emoji, as in `~/Splits/Pokémon "Red" #2.lss`): they round-trip exactly, as values and as the `layout` of a window. Test in Task 1.
3. **A hand-edited file**: whole numbers for the frame (`x = 100`), a recent list longer than 10 or with duplicates, an empty file, keys from a newer version. The first three load (the list trimmed and deduplicated), and unknown keys are ignored. Tests in Task 1.
4. **A save that fails** (the folder is a file, the disk is full): the change still applies for the session, the failure is logged once per save, and the next change tries again. Test in Task 2.
5. **An update that changes nothing** (the same Always on Top value, the same frame): no write, so moving the window doesn't rewrite the file with identical contents. Test in Task 2.

- Decoding a `Double` accepts a TOML integer.
- The test bundles don't depend on the package: the hosted unit tests reach it only through `Settings`' helpers, so it is linked once, into the app.

`App/Config/RecentFiles.swift`:

```swift
/// A recent files list: most recent first, each path once, at most 10 (spec §7, §11).
struct RecentFiles: Codable, Equatable, Sendable {
    static let limit = 10

    private(set) var paths: [String] = []

    /// A list holding `paths` in order, without empty paths or repeats, trimmed to the limit.
    /// A list read from a hand-edited file goes through here too.
    init(_ paths: [String] = []) {
        // Adding from the oldest keeps the order and the first of any repeat.
        for path in paths.reversed() where !path.isEmpty {
            add(path)
        }
    }

    /// Puts `path` first, moving it if it is already in the list.
    mutating func add(_ path: String) {
        paths.removeAll { $0 == path }
        paths.insert(path, at: 0)
        if paths.count > Self.limit {
            paths.removeLast(paths.count - Self.limit)
        }
    }

    mutating func remove(_ path: String) {
        paths.removeAll { $0 == path }
    }

    /// Clear Menu.
    mutating func clear() {
        paths.removeAll()
    }

    init(from decoder: any Decoder) throws {
        self.init(try decoder.singleValueContainer().decode([String].self))
    }

    func encode(to encoder: any Encoder) throws {
        var container = encoder.singleValueContainer()
        try container.encode(paths)
    }
}
```

`App/Config/Settings.swift`:

```swift
import Foundation
import TOML

/// Everything the app remembers between launches, stored in `app.toml` (spec §11). The splits
/// and layouts themselves stay wherever the user keeps them; only their paths are stored.
struct Settings: Codable, Equatable, Sendable {
    var lastSplitsPath: String?
    var lastLayoutPath: String?
    var recentSplits = RecentFiles()
    var recentLayouts = RecentFiles()
    /// The window's frame for each layout, by the layout's path (spec §6).
    var windows: [LayoutWindow] = []
    var alwaysOnTop = false
    /// The last URL used in Connect to Server (spec §8.1).
    var lastServerURL: String?

    /// The defaults, used when there is no file.
    init() {}

    /// The frame saved for the layout at `path`, if any.
    func frame(forLayout path: String) -> WindowFrame? {
        windows.first { $0.layout == path }?.frame
    }

    /// Saves `frame` for the layout at `path`, replacing any frame saved for it.
    mutating func setFrame(_ frame: WindowFrame, forLayout path: String) {
        if let index = windows.firstIndex(where: { $0.layout == path }) {
            windows[index].frame = frame
        } else {
            windows.append(LayoutWindow(layout: path, frame: frame))
        }
    }

    /// Settings read from the text of `app.toml`. Throws if it isn't TOML, or a key has the
    /// wrong type.
    static func decode(_ data: Data) throws -> Settings {
        try TOMLDecoder().decode(Settings.self, from: data)
    }

    /// The settings as TOML, keys sorted so the file doesn't reorder between saves.
    func tomlText() throws -> String {
        let encoder = TOMLEncoder()
        encoder.outputFormatting = [.sortedKeys]
        return try encoder.encodeToString(self)
    }

    /// Why reading or writing failed, for the log. swift-toml's errors name the line and column.
    static func reason(for error: any Error) -> String {
        switch error {
        case let error as TOMLDecodingError: error.description
        case let error as TOMLEncodingError: error.description
        default: error.localizedDescription
        }
    }

    // Explicit keys, never a key strategy: a strategy could rewrite them, and the file's keys
    // are part of the spec (§11).
    private enum CodingKeys: String, CodingKey {
        case lastSplitsPath = "last_splits"
        case lastLayoutPath = "last_layout"
        case recentSplits = "recent_splits"
        case recentLayouts = "recent_layouts"
        case windows
        case alwaysOnTop = "always_on_top"
        case lastServerURL = "last_server_url"
    }

    /// Every key is optional, so a file from an older version, or edited by hand, still reads.
    /// Unknown keys are ignored. A key with the wrong type throws.
    init(from decoder: any Decoder) throws {
        let container = try decoder.container(keyedBy: CodingKeys.self)
        lastSplitsPath = try container.decodeIfPresent(String.self, forKey: .lastSplitsPath)
        lastLayoutPath = try container.decodeIfPresent(String.self, forKey: .lastLayoutPath)
        recentSplits =
            try container.decodeIfPresent(RecentFiles.self, forKey: .recentSplits) ?? RecentFiles()
        recentLayouts =
            try container.decodeIfPresent(RecentFiles.self, forKey: .recentLayouts)
            ?? RecentFiles()
        windows = try container.decodeIfPresent([LayoutWindow].self, forKey: .windows) ?? []
        alwaysOnTop = try container.decodeIfPresent(Bool.self, forKey: .alwaysOnTop) ?? false
        lastServerURL = try container.decodeIfPresent(String.self, forKey: .lastServerURL)
    }

    func encode(to encoder: any Encoder) throws {
        var container = encoder.container(keyedBy: CodingKeys.self)
        try container.encodeIfPresent(lastSplitsPath, forKey: .lastSplitsPath)
        try container.encodeIfPresent(lastLayoutPath, forKey: .lastLayoutPath)
        try container.encode(recentSplits, forKey: .recentSplits)
        try container.encode(recentLayouts, forKey: .recentLayouts)
        try container.encode(windows, forKey: .windows)
        try container.encode(alwaysOnTop, forKey: .alwaysOnTop)
        try container.encodeIfPresent(lastServerURL, forKey: .lastServerURL)
    }
}

/// A window's position and size, in screen points, as AppKit gives them (origin at the bottom
/// left of the main screen).
struct WindowFrame: Equatable, Sendable {
    var x: Double
    var y: Double
    var width: Double
    var height: Double

    /// Whether the frame can be given to a window: finite, with a positive size. A
    /// hand-edited file can hold anything. Whether it is on a screen is for the window to decide.
    var isUsable: Bool {
        [x, y, width, height].allSatisfy(\.isFinite) && width > 0 && height > 0
    }
}

/// The frame saved for one layout. Written flat, as one table of `windows`.
struct LayoutWindow: Codable, Equatable, Sendable {
    var layout: String
    var frame: WindowFrame

    private enum CodingKeys: String, CodingKey {
        case layout, x, y, width, height
    }

    init(layout: String, frame: WindowFrame) {
        self.layout = layout
        self.frame = frame
    }

    init(from decoder: any Decoder) throws {
        let container = try decoder.container(keyedBy: CodingKeys.self)
        layout = try container.decode(String.self, forKey: .layout)
        frame = WindowFrame(
            x: try container.decode(Double.self, forKey: .x),
            y: try container.decode(Double.self, forKey: .y),
            width: try container.decode(Double.self, forKey: .width),
            height: try container.decode(Double.self, forKey: .height))
    }

    func encode(to encoder: any Encoder) throws {
        var container = encoder.container(keyedBy: CodingKeys.self)
        try container.encode(layout, forKey: .layout)
        try container.encode(frame.x, forKey: .x)
        try container.encode(frame.y, forKey: .y)
        try container.encode(frame.width, forKey: .width)
        try container.encode(frame.height, forKey: .height)
    }
}
```

```swift
import Foundation

/// Reads `app.toml` at launch and writes it when a setting changes (spec §11, §10).
@MainActor
final class SettingsStore {
    static let fileName = "app.toml"
    static let badFileName = "app.toml.bad"
    /// The first line of the file, so someone opening it knows what it is.
    static let header =
        "# LiveSplit One for macOS settings. The app rewrites this file when a setting changes.\n\n"

    /// What reading the file at launch found.
    enum LoadOutcome: Equatable {
        /// No file yet: the defaults.
        case missing
        case loaded
        /// The file couldn't be read or parsed. It was kept as `app.toml.bad`, and the defaults
        /// are used.
        case recovered(reason: String)
        /// The file couldn't be read or parsed, nor moved aside. The defaults are used, and
        /// nothing is saved this session, so the file isn't overwritten.
        case unrecoverable(reason: String)
    }

    let directory: URL
    var file: URL { directory.appending(path: Self.fileName) }
    private(set) var settings: Settings
    let loadOutcome: LoadOutcome

    private let log: Log

    init(directory: URL, log: Log = .shared) {
        self.directory = directory
        self.log = log
        (settings, loadOutcome) = Self.load(from: directory, log: log)
    }

    /// Changes the settings and saves them, if `change` changed anything.
    func update(_ change: (inout Settings) -> Void) {
        var changed = settings
        change(&changed)
        guard changed != settings else { return }
        settings = changed
        save()
    }

    private func save() {
        // Never write over a file that couldn't be read or moved aside.
        if case .unrecoverable = loadOutcome { return }
        do {
            let text = Self.header + (try settings.tomlText())
            try FileManager.default.createDirectory(
                at: directory, withIntermediateDirectories: true)
            // Atomic: a crash or a full disk mid-write leaves the old file whole.
            try Data(text.utf8).write(to: file, options: .atomic)
            log.record(.app, "Saved the settings to \(file.path)")
        } catch {
            log.record(
                .error, "Couldn't save the settings to \(file.path): \(Settings.reason(for: error))")
        }
    }

    /// Reads the settings in `directory`, moving a broken file aside.
    private static func load(from directory: URL, log: Log) -> (Settings, LoadOutcome) {
        let file = directory.appending(path: fileName)
        let bad = directory.appending(path: badFileName)
        guard FileManager.default.fileExists(atPath: file.path) else {
            log.record(.app, "No settings file yet at \(file.path), so the defaults are used")
            return (Settings(), .missing)
        }

        let reason: String
        do {
            let settings = try Settings.decode(Data(contentsOf: file))
            log.record(.app, "Read the settings from \(file.path)")
            return (settings, .loaded)
        } catch {
            reason = Settings.reason(for: error)
        }

        do {
            if FileManager.default.fileExists(atPath: bad.path) {
                try FileManager.default.removeItem(at: bad)
            }
            try FileManager.default.moveItem(at: file, to: bad)
            log.record(
                .error,
                "Couldn't read the settings in \(file.path), so the defaults are used and the "
                    + "file is kept as \(badFileName): \(reason)")
            return (Settings(), .recovered(reason: reason))
        } catch {
            log.record(
                .error,
                "Couldn't read the settings in \(file.path) (\(reason)), nor keep it as "
                    + "\(badFileName) (\(error.localizedDescription)), so the defaults are "
                    + "used and changes aren't saved until the app restarts")
            return (Settings(), .unrecoverable(reason: reason))
        }
    }
}
```
