# Logging Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Record what the app does in daily log files in `~/Library/Logs/livesplit-one-macos/` and in the unified log, with the same categories, rotation, retention and size cap as livesplit-asr-bridge, so that every later issue can log and a user can send the day's file with a bug report (issue #17).

**Architecture:** `Log` is the one entry point: `Log.shared.record(.connection, "…")` from any thread. Behind a lock it sends each line to the unified log (`os.Logger`, one per category) and to `DiskLog`, a port of livesplit-asr-bridge's `src/logging/disk.rs`: one file per local day, files older than 7 days deleted at launch and at each rotation, and past 50 MB only errors. If the folder can't be written, `Log` stops writing files and keeps sending to the unified log. `GameTimeLogFilter` decides which server messages are logged, for #14. Test builds read a launch argument that moves the log folder, which starts the E2E harness (#18).

**Tech Stack:** Swift 6, Foundation (`FileHandle`, `FileManager`, `Calendar`), `os` (`Logger`, `OSLogStore`), AppKit (`NSWorkspace`, `NSAlert`), Swift Testing, XCUITest, XcodeGen.

**Spec:** `docs/superpowers/specs/2026-10-09-livesplit-one-macos-design.md`, sections 10 (the last row), 12, 14.1 and 14.2. Issue: #17. Model: livesplit-asr-bridge `src/logging/{mod,disk,entry}.rs` and its spec §8.1 (repeated game times).

**Branch and worktree:** `feat/logging`, at `../livesplit-one-macos-wt/logging`. **PR title:** `feat: log to daily files and the unified log`. **PR body:** `Closes #17`, using the pull request template. One pull request for the whole plan; each task is one commit.

## Global Constraints

- Log folder: `~/Library/Logs/livesplit-one-macos/` (spec §12.2). File name: `livesplit-one-macos-YYYY-MM-DD.log`, the date in the user's time zone.
- Line format, as livesplit-asr-bridge: local time to milliseconds, two spaces, the category's tag, two spaces, the message, `\n`. For example `19:31:01.254  CONNECTION  Connected to 192.168.1.20`. Tags: `ERROR`, `CONNECTION`, `TIMER`, `APP`.
- Unified log: subsystem `dev.alexcosta.livesplit-one-macos`, categories `Errors`, `Connection`, `Timer`, `App` (spec §12.1, §12.3). Messages are `privacy: .public`, otherwise Console.app shows `<private>` and the unified log is useless for bug reports. Errors at `.error`, everything else at `.notice`: `.info` and `.debug` aren't shown in Console.app by default.
- Retention: a file whose date is more than 7 days before today is deleted, at launch and when the day changes. Files in the folder that aren't log files are never touched.
- Cap: `50 * 1024 * 1024` bytes per day's file. Past it, only `ERROR` lines are written, after the one line `Today's log reached 50 MB, so only errors are written to it until tomorrow` (in the `APP` category). The cap holds across a relaunch on the same day.
- Every category is written to disk (spec §12.2). Nothing is filtered by level.
- `Log.record` is safe from any thread and never throws or crashes. A log that can't be written must never stop the app (spec §10).
- Launch arguments for tests are compiled only into Debug builds (`#if DEBUG`), which `xcodebuild test` and CI's `build-for-testing` use. The release build (`scripts/build-app.sh`, Release configuration) must not contain them.
- Swift is formatted with `swift format` using `.swift-format` (4 spaces, 100 columns) and must pass `swift format lint --strict`.
- Commits: Conventional Commits, signed, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **The log folder can't be created or written** (a file named `livesplit-one-macos` where the folder should be, a full disk, permissions): the app launches as normal, one error line saying the log isn't saved reaches the unified log, and every later line still reaches it. Tests in Task 3.
2. **Lines from several threads at once** (server commands on a background queue while the menu acts on the main thread): each line is written whole, on its own line, and none are lost. Test in Task 3.
3. **Midnight while the app runs, and a daylight saving change:** the first line after midnight goes in the new day's file and old files are deleted then, and a 23- or 25-hour day doesn't make a 7-day-old file look 6 or 8 days old. Tests in Tasks 1 and 2.
4. **Test runs writing to the developer's own log folder:** unit and headless UI tests run inside the app, which logs its launch. In Debug builds a test host logs to a temporary folder instead, and E2E runs log to a folder they choose. Task 4 tests both; Task 6 checks the developer's folder by hand.
5. **The bridge sending the game time on every tick:** the file gets one line per run of `setGameTime`, not hundreds a second, while every other command is logged. Test in Task 5.

Key facts:
- `Calendar.dateComponents([.nanosecond], …)` goes through floating point and can turn 254 ms into 253.999…, so the time is rounded to whole milliseconds once, from `timeIntervalSince1970`, and hours, minutes and seconds come from that rounded value. That way 19:31:01.9996 is written `19:31:02.000`, not `19:31:01.000`.
- Days are compared at noon, so a daylight saving change (a 23- or 25-hour day) never shifts the count.
- Europe/London has a daylight saving change on 2026-10-25, used by the tests.

```swift
    static let london: Calendar = {
        var calendar = Calendar(identifier: .gregorian)
        calendar.timeZone = TimeZone(identifier: "Europe/London")!
        return calendar
    }()

    /// A local time in London.
    static func date(
        _ year: Int, _ month: Int, _ day: Int, _ hour: Int = 19, _ minute: Int = 31,
        _ second: Int = 1, milliseconds: Int = 254
    ) -> Date {
        let components = DateComponents(
            year: year, month: month, day: day, hour: hour, minute: minute, second: second)
        return london.date(from: components)!

    }
```

`App/Log/LogEntry.swift`:

```swift
import Foundation

/// One logged line.
struct LogEntry: Equatable, Sendable {
    /// When it was recorded.
    var time: Date
    var category: LogCategory
    var message: String

    /// The line as written to the log file: local time to the millisecond, tag and message, with
    /// a newline.
    func line(in calendar: Calendar) -> String {
        // Rounded once, so the milliseconds and the seconds always agree.
        let milliseconds = Int64((time.timeIntervalSince1970 * 1000).rounded())
        let second = Date(timeIntervalSince1970: TimeInterval(milliseconds / 1000))
        let parts = calendar.dateComponents([.hour, .minute, .second], from: second)
        let clock = String(
            format: "%02d:%02d:%02d.%03d", parts.hour ?? 0, parts.minute ?? 0, parts.second ?? 0,
            Int(milliseconds % 1000))
        return "\(clock)  \(category.tag)  \(message)\n"
    }
}
```

`App/Log/LogDay.swift`:

```swift
import Foundation

/// A day in the user's calendar, which names a log file.
struct LogDay: Hashable, Comparable, Sendable {
    let year: Int
    let month: Int
    let day: Int

    init(year: Int, month: Int, day: Int) {
        self.year = year
        self.month = month
        self.day = day
    }

    /// The day `date` falls on in `calendar`.
    init(_ date: Date, in calendar: Calendar) {
        let parts = calendar.dateComponents([.year, .month, .day], from: date)
        self.init(year: parts.year ?? 0, month: parts.month ?? 0, day: parts.day ?? 0)
    }

    /// A day written as `YYYY-MM-DD`, or `nil` if `text` isn't a real date in that form.
    init?(text: String) {
        let parts = text.split(separator: "-", omittingEmptySubsequences: false)
        guard parts.count == 3, parts[0].count == 4, parts[1].count == 2, parts[2].count == 2,
            parts.allSatisfy({ $0.allSatisfy(\.isASCII) && $0.allSatisfy(\.isNumber) }),
            let year = Int(parts[0]), let month = Int(parts[1]), let day = Int(parts[2])
        else { return nil }
        let components = DateComponents(year: year, month: month, day: day)
        guard components.isValidDate(in: Calendar(identifier: .gregorian)) else { return nil }
        self.init(year: year, month: month, day: day)
    }

    /// `YYYY-MM-DD`.
    var text: String { String(format: "%04d-%02d-%02d", year, month, day) }

    /// Whole days from this day to `later`; negative if `later` is earlier.
    func days(until later: LogDay, in calendar: Calendar) -> Int {
        // At noon, so a 23- or 25-hour day never changes the count.
        guard let start = calendar.date(from: noon), let end = calendar.date(from: later.noon)
        else { return 0 }
        return calendar.dateComponents([.day], from: start, to: end).day ?? 0
    }

    static func < (lhs: LogDay, rhs: LogDay) -> Bool {
        (lhs.year, lhs.month, lhs.day) < (rhs.year, rhs.month, rhs.day)
    }

    private var noon: DateComponents {
        DateComponents(year: year, month: month, day: day, hour: 12)
    }
}

/// The names of the log files: `livesplit-one-macos-YYYY-MM-DD.log` (spec §12.2).
enum LogFileName {
    static let prefix = "livesplit-one-macos-"
    static let suffix = ".log"

    /// The name of the file for `day`.
    static func of(_ day: LogDay) -> String { prefix + day.text + suffix }

    /// The day a log file is for, from its name, or `nil` if it isn't a log file.
    static func day(of name: String) -> LogDay? {
        guard name.hasPrefix(prefix), name.hasSuffix(suffix),
            name.count > prefix.count + suffix.count
        else { return nil }
        return LogDay(text: String(name.dropFirst(prefix.count).dropLast(suffix.count)))
    }
}
```

Key facts:
- Each line is appended through a file descriptor opened with `O_APPEND`, so a second copy of the app (`open -n`) writing the same day's file adds lines rather than writing over them.
- The cap line is written after the cap, so on reopening a file past the cap only that part is read to see whether it was already written. This is what keeps the cap after a relaunch, as in the bridge.

```swift
import Foundation

/// A new empty folder, deleted with everything in it when this goes away.
final class TemporaryFolder {
    let url: URL

    init() throws {
        url = FileManager.default.temporaryDirectory
            .appending(path: "lso-tests-\(UUID().uuidString)", directoryHint: .isDirectory)
        try FileManager.default.createDirectory(at: url, withIntermediateDirectories: true)
    }

    deinit {
        try? FileManager.default.removeItem(at: url)
    }

    /// The names of the files in the folder, sorted.
    func names() throws -> [String] {
        try FileManager.default.contentsOfDirectory(atPath: url.path).sorted()
    }

    /// The text of the file `name` in the folder.
    func read(_ name: String) throws -> String {
        try String(contentsOf: url.appending(path: name), encoding: .utf8)
    }

    /// Creates the file `name` in the folder with `text`.
    func write(_ name: String, _ text: String = "") throws {
        try text.write(to: url.appending(path: name), atomically: true, encoding: .utf8)
    }
}
```

`App/Log/DiskLog.swift`:

```swift
import Foundation

/// Why a line couldn't be written to the log file.
struct DiskLogError: Error, Equatable {
    let message: String
}

/// The log files: one per day, kept for 7 days, with a per-day size cap (spec §12.2). A port of
/// livesplit-asr-bridge's `src/logging/disk.rs`.
///
/// Every category is written. Past the cap, only errors are written, after one line saying the
/// cap was reached. Not thread-safe: `Log` serialises every call.
struct DiskLog {
    /// Files more than this many days older than today are deleted.
    static let retentionDays = 7
    /// The size past which only errors are written to a day's file: 50 MB.
    static let dailyCap = 50 * 1024 * 1024
    /// The line written once when a day's file reaches the cap.
    static let capMessage =
        "Today's log reached 50 MB, so only errors are written to it until tomorrow"

    let directory: URL
    private let calendar: Calendar
    private let cap: Int
    private var file: DayFile?

    private init(directory: URL, calendar: Calendar, cap: Int) {
        self.directory = directory
        self.calendar = calendar
        self.cap = cap
    }

    /// A writer for the log folder `directory`, after deleting the files that are too old on
    /// `today`. Returns what couldn't be deleted.
    static func open(
        directory: URL, today: LogDay, calendar: Calendar, cap: Int = dailyCap
    ) -> (DiskLog, [String]) {
        let log = DiskLog(directory: directory, calendar: calendar, cap: cap)
        return (log, log.deleteOld(today: today))
    }

    /// Writes `entry` to its day's file, starting a new file when the day changes and then
    /// deleting the files that are too old. Returns what couldn't be deleted. Throws if the line
    /// couldn't be written.
    mutating func write(_ entry: LogEntry) throws(DiskLogError) -> [String] {
        let day = LogDay(entry.time, in: calendar)
        var errors: [String] = []
        if file?.day != day {
            let rotating = file != nil
            file = nil
            if rotating {
                errors = deleteOld(today: day)
            }
            file = try DayFile.open(directory: directory, day: day, cap: cap)
        }
        guard let file else { return errors }

        if file.size >= cap && entry.category != .error {
            if !file.capped {
                var marker = entry
                marker.category = .app
                marker.message = Self.capMessage
                try file.append(marker.line(in: calendar))
                file.capped = true
            }
            return errors
        }
        try file.append(entry.line(in: calendar))
        return errors
    }

    /// Deletes the log files more than `retentionDays` older than `today`. Other files in the
    /// folder are left alone. Returns what couldn't be deleted.
    private func deleteOld(today: LogDay) -> [String] {
        let names: [String]
        do {
            names = try FileManager.default.contentsOfDirectory(atPath: directory.path)
        } catch CocoaError.fileReadNoSuchFile {
            return []
        } catch {
            return [
                "Couldn't delete old log files in \(directory.path): \(error.localizedDescription)"
            ]
        }
        var errors: [String] = []
        for name in names {
            guard let day = LogFileName.day(of: name),
                day.days(until: today, in: calendar) > Self.retentionDays
            else { continue }
            let path = directory.appending(path: name)
            do {
                try FileManager.default.removeItem(at: path)
            } catch {
                errors.append(
                    "Couldn't delete the old log file \(path.path): \(error.localizedDescription)")
            }
        }
        return errors
    }
}

/// The open file of one day.
private final class DayFile {
    let day: LogDay
    private let handle: FileHandle
    private(set) var size: Int
    /// Whether the cap was reached and the line saying so written.
    var capped: Bool

    private init(day: LogDay, handle: FileHandle, size: Int, capped: Bool) {
        self.day = day
        self.handle = handle
        self.size = size
        self.capped = capped
    }

    deinit {
        try? handle.close()
    }

    /// Opens the file of `day` in `directory` to add to it, creating the folder and the file if
    /// needed.
    static func open(directory: URL, day: LogDay, cap: Int) throws(DiskLogError) -> DayFile {
        let url = directory.appending(path: LogFileName.of(day))
        func failure(_ reason: String) -> DiskLogError {
            DiskLogError(message: "couldn't open \(url.path): \(reason)")
        }
        do {
            try FileManager.default.createDirectory(
                at: directory, withIntermediateDirectories: true)
        } catch {
            throw failure(error.localizedDescription)
        }
        // O_APPEND: every write goes to the end, even with another copy of the app writing.
        let descriptor = Darwin.open(url.path, O_WRONLY | O_APPEND | O_CREAT | O_CLOEXEC, 0o644)
        guard descriptor >= 0 else { throw failure(String(cString: strerror(errno))) }
        let handle = FileHandle(fileDescriptor: descriptor, closeOnDealloc: true)

        let size: Int
        let capped: Bool
        do {
            let attributes = try FileManager.default.attributesOfItem(atPath: url.path)
            size = (attributes[.size] as? NSNumber)?.intValue ?? 0
            // The line saying the cap was reached is always after the cap, so only that part
            // of the file needs reading.
            if size >= cap {
                let reader = try FileHandle(forReadingFrom: url)
                defer { try? reader.close() }
                try reader.seek(toOffset: UInt64(cap))
                let rest = try reader.readToEnd() ?? Data()
                capped = String(decoding: rest, as: UTF8.self).contains(DiskLog.capMessage)
            } else {
                capped = false
            }
        } catch {
            throw failure(error.localizedDescription)
        }
        return DayFile(day: day, handle: handle, size: size, capped: capped)
    }

    func append(_ line: String) throws(DiskLogError) {
        let data = Data(line.utf8)
        do {
            try handle.write(contentsOf: data)
        } catch {
            throw DiskLogError(
                message: "couldn't write the log file: \(error.localizedDescription)")
        }
        size += data.count
    }
}
```

```swift
import os

/// Where every line also goes, besides the log file (spec §12.3).
protocol UnifiedLogSink: Sendable {
    func send(_ entry: LogEntry)
}

/// The system's unified log, so lines show in Console.app's live stream next to system messages
/// such as local network permission decisions.
struct SystemUnifiedLog: UnifiedLogSink {
    static let subsystem = "dev.alexcosta.livesplit-one-macos"

    private let loggers: [LogCategory: Logger]

    init() {
        var loggers: [LogCategory: Logger] = [:]
        for category in LogCategory.allCases {
            loggers[category] = Logger(subsystem: Self.subsystem, category: category.unifiedName)
        }
        self.loggers = loggers
    }

    func send(_ entry: LogEntry) {
        guard let logger = loggers[entry.category] else { return }
        // Public, or Console.app shows <private> instead of the message. The messages hold
        // file paths and server addresses, nothing secret (spec §13).
        if entry.category == .error {
            logger.error("\(entry.message, privacy: .public)")
        } else {
            // Not .info: Console.app hides info and debug messages by default.
            logger.notice("\(entry.message, privacy: .public)")
        }
    }
}
```

`App/Log/Log.swift`:

```swift
import Foundation

/// Records what the app does, in the day's log file and the unified log (spec §12).
///
/// Safe to call from any thread: server commands are logged from a background queue (spec
/// §8.2). `@unchecked Sendable` because `lock` guards all mutable state; `Mutex` would need
/// macOS 15.
final class Log: @unchecked Sendable {
    /// The log folder.
    let directory: URL

    private let lock = NSLock()
    /// The log files' writer, or `nil` once writing to them failed.
    private var disk: DiskLog?
    private let unified: any UnifiedLogSink
    private let now: @Sendable () -> Date

    init(
        directory: URL, unified: any UnifiedLogSink = SystemUnifiedLog(),
        calendar: Calendar = .autoupdatingCurrent, cap: Int = DiskLog.dailyCap,
        now: @escaping @Sendable () -> Date = { Date() }
    ) {
        self.directory = directory
        self.unified = unified
        self.now = now
        let (disk, errors) = DiskLog.open(
            directory: directory, today: LogDay(now(), in: calendar), calendar: calendar,
            cap: cap)
        self.disk = disk
        for error in errors {
            record(.error, error)
        }
    }

    /// Records a line, stamped with the current time. Never fails: if the file can't be
    /// written, the line still reaches the unified log.
    func record(_ category: LogCategory, _ message: String) {
        let entry = LogEntry(time: now(), category: category, message: message)
        lock.withLock {
            unified.send(entry)
            for error in writeToDisk(entry) {
                let line = LogEntry(time: entry.time, category: .error, message: error)
                unified.send(line)
                // Same day as `entry`, so this write can't rotate and report more errors.
                _ = writeToDisk(line)
            }
        }
    }

    /// Writes `entry` to the file. Returns the errors to record. Called with `lock` held.
    private func writeToDisk(_ entry: LogEntry) -> [String] {
        guard var writer = disk else { return [] }
        do {
            let errors = try writer.write(entry)
            disk = writer
            return errors
        } catch {
            // Sent to the unified log only: writing it to the file would fail too.
            disk = nil
            unified.send(
                LogEntry(
                    time: entry.time, category: .error,
                    message: "Couldn't write the log file, so the log isn't saved to disk "
                        + "until the app restarts: \(error.message)"))
            return []
        }
    }
}
```

```swift
/// Folders that test runs choose at launch, so tests never touch the user's own settings and
/// logs (spec §14.2). Only Debug builds, which tests use, read them; a Release build doesn't

enum LaunchOverrides {
    #if DEBUG
        static let logDirectoryArgument = "-LSOLogDirectory"

        /// The log folder for this run, if a test chose one.
        static var logDirectory: URL? {
            directory(after: logDirectoryArgument, in: ProcessInfo.processInfo.arguments)
                ?? testHostDirectory("Logs", environment: ProcessInfo.processInfo.environment)
        }

        /// The absolute folder after `argument`, as in `-LSOLogDirectory /private/tmp/x`.
        static func directory(after argument: String, in arguments: [String]) -> URL? {
            guard let index = arguments.firstIndex(of: argument), index + 1 < arguments.count
            else { return nil }
            let path = arguments[index + 1]
            guard path.hasPrefix("/") else { return nil }
            return URL(filePath: path, directoryHint: .isDirectory)

        /// don't add to the developer's own files.
        static func testHostDirectory(_ name: String, environment: [String: String]) -> URL? {
            guard environment["XCTestConfigurationFilePath"] != nil else { return nil }
            return FileManager.default.temporaryDirectory
                .appending(path: "lso-test-host/\(name)", directoryHint: .isDirectory)
        }
```

`App/Log/GameTimeLogFilter.swift`:

```swift
import Foundation

/// Which server messages are logged (spec §12.1). A bridge can set the game time on every tick,
/// so only the first `setGameTime` of a run is logged; any other command ends the run. The
/// messages are still applied and answered. The same rule as livesplit-asr-bridge's. One per
/// connection.
struct GameTimeLogFilter {
    private var inGameTimeRun = false

    /// Whether to log `message`, a server protocol message, with its reply and its event.
    mutating func shouldLog(_ message: String) -> Bool {
        let isGameTime = Self.command(of: message) == "setGameTime"
        defer { inGameTimeRun = isGameTime }
        return !(isGameTime && inGameTimeRun)
    }

    /// The `command` of a server protocol message, or `nil` if it has none.
    static func command(of message: String) -> String? {
        guard let object = try? JSONSerialization.jsonObject(with: Data(message.utf8)),
            let fields = object as? [String: Any]
        else { return nil }
        return fields["command"] as? String
    }
}
```

```swift
import AppKit

/// Open Log Folder (spec §12.2): opens the log folder in Finder.
@MainActor
struct LogFolderOpener {
    var createDirectory: (URL) throws -> Void
    var openInFinder: (URL) -> Bool
    var log: Log

    static var system: LogFolderOpener {
        LogFolderOpener(
            createDirectory: {
                try FileManager.default.createDirectory(at: $0, withIntermediateDirectories: true)
            },
            openInFinder: { NSWorkspace.shared.open($0) },
            log: .shared)
    }

    /// Opens `folder`, creating it first in case no line could be written yet. Returns false,
    /// after logging why, if it couldn't.
    func open(_ folder: URL) -> Bool {
        do {
            try createDirectory(folder)
        } catch {
            log.record(
                .error, "Couldn't create the log folder \(folder.path): \(error.localizedDescription)")
            return false
        }
        guard openInFinder(folder) else {
            log.record(.error, "Couldn't open the log folder \(folder.path) in Finder")
            return false
        }
        return true
    }
}

        alert.messageText = "Couldn't open the log folder"
        alert.informativeText = "The log files are in \(folder.path)."
        alert.addButton(withTitle: "OK")
        return alert
    }
}
```

```swift
import XCTest

/// Launches the app with its own folders, so E2E runs never touch the user's settings and logs
/// (spec §14.2).
///
/// The test runner is sandboxed, with read-only access to the whole disk: it can read what the
/// app writes but can't create files. So the folders are under /private/tmp, outside the
/// runner's container, and the app creates them.
@MainActor
final class E2EApp {
    let app = XCUIApplication()
    let root = URL(
        filePath: "/private/tmp/lso-e2e-\(UUID().uuidString)", directoryHint: .isDirectory)

    var logFolder: URL { root.appending(path: "Logs", directoryHint: .isDirectory) }
    var timerWindow: XCUIElement { app.windows["timer-window"] }

    func launch() {
        app.launchArguments += ["-LSOLogDirectory", logFolder.path]
        app.launch()
    }

    /// All of the log files' text, once it contains `text`, or `nil` if it doesn't within
    /// `timeout` seconds.
    func logText(containing text: String, timeout: TimeInterval = 10) -> String? {
        let deadline = Date().addingTimeInterval(timeout)
        repeat {
            let names =
                (try? FileManager.default.contentsOfDirectory(atPath: logFolder.path)) ?? []
            let all = names.filter { $0.hasSuffix(".log") }.sorted()
                .compactMap { try? String(contentsOf: logFolder.appending(path: $0), encoding: .utf8) }
                .joined()
            if all.contains(text) { return all }
            RunLoop.current.run(until: Date().addingTimeInterval(0.2))
        } while Date() < deadline
        return nil
    }
}
```
